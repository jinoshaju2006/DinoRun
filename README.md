# Dino Run 🦖

Offline landscape 2D endless runner for Android using the supplied Dino Run artwork.

## Features
- 4 selectable dragons with increasing base speed
- Endless score with local high score
- Gradually increasing difficulty
- Cactus collision / game over
- 30 / 60 / 90 FPS selection
- Pause / resume / restart
- Offline sound effects and music
- Game-over and win screens using supplied artwork
- GitHub Actions workflow builds the debug APK

## Build on GitHub
1. Create a GitHub repository.
2. Upload all files from this folder.
3. Push to `main`.
4. Open **Actions → Build Dino Run APK**.
5. Download the `DinoRun-debug-apk` artifact after the workflow finishes.

The APK is unsigned debug build and is suitable for testing on Android.
